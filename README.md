# Aplicación Base

Usa el PRD definido como referencia principal y construye la primera iteración de esta aplicación web en español.

 

Instrucciones obligatorias:

- Respeta estrictamente el alcance de la versión 1.

- Mantén un diseño responsive, profesional, sobrio y claro.

- Implementa solo la estructura base, navegación, formulario o módulos principales.

- Valida desde el inicio los campos de entrada esenciales.

- Prepara espacios para resultados, dashboard, reporte o checklist, según el PRD.

- No agregues funcionalidades fuera de alcance.

- No agregues pagos ni integraciones externas en esta primera iteración.

- No cambies el lenguaje profesional definido en el PRD
